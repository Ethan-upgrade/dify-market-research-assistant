# 调研范围：六个维度怎么起作用

范围不是「写在报告头上的标签」，它会被拼进 **prompt**，真实改变检索式和结论口径。
实现上对应 `standalone/mra/config.py` 的 `Scope.search_scope()` / `report_scope()`。

## 1. 地区 `market`

| 选项 | 进检索式的地区词 | 报告口径 |
|---|---|---|
| 不限（全球为主） | 不加地区词 | 全球为主，中国作为重点对照 |
| 中国大陆 | 中国 | 仅中国 |
| 中国 + 全球对照 | 中国 / 全球 | 两套口径并列 |
| 北美 / 欧洲 / 东南亚 / 日韩 / 中东 | 对应地区 | 对应地区 |

选「不限」时**不会**往检索式里塞「全球」这种噪音词——这是刻意的，加了反而降低检索命中。

## 2. 行业 `industry`

决定优先参考哪类公开数据源：消费品看电商/社媒，SaaS 看财报/技术博客，新能源看政策文件。

## 3. 目的 `research_purpose`

决定**第七章行动建议的落点**：

| 目的 | 建议落点 |
|---|---|
| 竞品分析 | 打法差异、份额攻防 |
| 市场进入 | 进入路径、壁垒、本地化 |
| 新品立项 | P0/P1/P2 前置尽调清单 |
| 投资尽调 | 增长质量、单位经济模型 |
| 定价策略 | 价格带分层、弹性 |
| 渠道策略 | 渠道结构与转化 |
| 行业概览 | 全景与趋势 |

## 4. 时间范围 `time_range`

只影响「优先采信哪几年的数据」，不做硬过滤（搜索引擎也没有这么细的过滤）。选「不限」时不写年份词。

## 5. 数据源偏好 `source_pref`

| 选项 | 压进检索式的关键词 | 报告里的可信度规则 |
|---|---|---|
| 优先券商研报/咨询报告 | 券商研报 行业报告 | 券商/咨询口径优先，自媒体只作旁证 |
| 优先官方统计/政府数据 | 统计局 海关 官方数据 | 官方口径优先，商业机构差异要标注 |
| 优先上市公司财报 | 财报 年报 分部收入 | 财报口径优先，估算值必须标注 |
| 优先新闻报道 | 新闻报道 最新动态 | 主流媒体近一年，注意转载去重 |
| 优先电商/社媒数据 | 电商 销量 评论 社媒 | 电商口径优先，注意平台差异 |

## 6. 检索深度 `depth`

| 值 | 循环轮数 | 检索次数 | 约耗时 | Tavily |
|---|---|---|---|---|
| 2 | 2 | 4 | ~50s | ~8 credits |
| 3 | 3 | 6 | ~90s | ~12 credits |
| 4 | 4 | 8 | ~130s | ~16 credits |

轮数之外还有两个「提前停」条件：模型说够了、或本轮零新增来源。

## 实测：同一句话，换个范围

| 输入 | 第 1 轮检索式 |
|---|---|
| `--market 中国大陆` | `2024年中国胶囊咖啡市场规模及增速` |
| `--market 北美` | `2024年北美胶囊咖啡市场规模及增速` |
| `--source 优先券商研报/咨询报告` | `… 券商研报 行业报告` 后缀 |

差异是**实际生成**的，不是拼接模板——检索式由模型根据范围重新组织。
